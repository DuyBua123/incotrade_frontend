# HƯỚNG DẪN CHẠY DỰ ÁN

## 1. Môi trường

- Node.js 20 trở lên
- npm package manager

## 2. Cài dependencies

Tại thư mục gốc của project, chay:

```powershell
npm install
```

## 3. Chạy môi trường development

```powershell
npm run dev
```

Project sẽ chạy bằng HTTPS:

```text
https://localhost:3000
```
